B2B T-Shirt Manufacturing Management Dashboard
Project Overview

An interactive Excel dashboard designed to monitor and analyze the overall operations of a B2B T-Shirt Manufacturing business. This project provides insights into sales, purchases, production, inventory, quality control, dispatch, and financial performance.

Key Features
Sales and Revenue Analysis
Purchase and Vendor Management
Production Performance Tracking
Inventory Management
Quality Control Analysis
Dispatch Monitoring
Financial Performance Analysis
GST and Receivables Tracking
Interactive Dashboard with Filters
Tools & Technologies
Microsoft Excel
Pivot Tables
Excel Formulas
Data Analysis
Data Visualization
Dashboard Development
Project Objective

To transform raw business data into meaningful insights through interactive dashboards, helping businesses monitor performance, identify trends, and make data-driven decisions.
