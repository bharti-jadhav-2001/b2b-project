# B2B T-Shirt Manufacturing Management Dashboard

## 📌 Project Overview

An interactive Excel dashboard designed to monitor and analyze the overall operations of a B2B T-Shirt Manufacturing business.

The dashboard provides meaningful insights into sales, purchases, production, inventory, quality control, dispatch, and financial performance, helping management make data-driven decisions.

## 🎯 Project Objective

The main objective of this project is to transform raw business data into meaningful insights using Excel dashboards, Pivot Tables, formulas, and data visualization.

It helps businesses:
- Monitor overall performance
- Track sales and revenue
- Manage inventory and production
- Monitor purchases and vendors
- Identify quality issues
- Track dispatch and receivables
- Analyze financial performance

## 🔑 Key Features

- Sales & Revenue Analysis
- Purchase & Vendor Management
- Production Performance Tracking
- Inventory Management
- Quality Control Analysis
- Dispatch Monitoring
- Financial Performance Analysis
- GST & Receivables Tracking
- Interactive Dashboard with Filters

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Development

## 📊 Dashboard Insights

The dashboard helps users analyze business performance through interactive filters, charts, KPIs, and summary reports.
